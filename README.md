# CHECKEDIN Capstone Research Website

Responsive, academic-style static website for **CHECKEDIN: A Web and Mobile Application for Attendance Monitoring and Event Management in the College of Computer Studies**.

## Publish with GitHub Pages
1. Upload `index.html` and this README to the root of the repository's default branch (usually `main`).
2. Open repository **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the default branch and the `/(root)` folder, then save.
5. Wait for GitHub Pages to finish publishing; its URL will appear in the Pages settings.

No build step or package installation is required.

## Complete the placeholders
- Replace the six screenshot placeholders in `index.html` with approved screenshots:
  - Administrator Dashboard (Figure 4.2)
  - Organization Officer Dashboard (Figure 4.3)
  - Professor Dashboard (Figure 4.4)
  - Events Form (Figure 4.5)
  - Workspace Report (Figure 4.6)
  - Workspace Analytics (Figure 4.7)
- Put image files in `assets/screenshots/` and update the corresponding gallery cards in `index.html`.
- Add the demo URL when a public recording is available.
- Researcher and adviser cards include portrait placeholders. Replace them with approved photos only with permission, keeping each person's name in the adjacent text.

The evaluation chart visualizes the reported means already listed in the page; the numeric labels remain available if motion is reduced or unavailable.

Do not publish student personal information, credentials, or sensitive attendance records in screenshots.
